# Contributing Guide

Thank you for considering contributing to this project!

## How to Contribute
- Read the [Architecture Guide](ARCHITECTURE.md) to understand the project structure.
- See the [Self-Hosting Guide](SELF_HOSTING_GUIDE.md) for deployment instructions.
- Follow the coding standards and commit message guidelines.
- Submit issues and pull requests in English.

## Issues
- Report bugs, feature requests, and documentation improvements.
- All issues must be written in English.
- Check for existing issues before submitting a new one.

## Internationalization
- To help with translations, use the structure `docs/pt-BR/`, `docs/es/`, etc.
