## 🤝 Como Contribuir com Traduções

Quer ajudar a traduzir a documentação? Veja nosso [guia de contribuição](../CONTRIBUTING.md#internationalization).

### Processo de Tradução

1. **Escolha um documento** da lista acima
2. **Crie um issue** informando que vai traduzir
3. **Traduza o documento** mantendo a formatação
4. **Abra um Pull Request** com a tradução
5. **Aguarde a revisão** de outros falantes nativos

### Diretrizes de Tradução

- **Mantenha a formatação** original (links, código, etc.)
- **Use linguagem clara** e acessível
- **Seja consistente** com a terminologia técnica
- **Adapte exemplos** quando necessário para o contexto brasileiro

## 📞 Contato
